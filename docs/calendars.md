# Holidays and time-of-use windows

This page sets out how `coned_billing` decides whether an interval falls in
a charge's window. It covers holiday sets, window semantics, and how both
interact with time zones and daylight saving time. Load-data rules are in
[`load_data.md`](load_data.md).

## Time zone

Every window and holiday test runs on New York civil time
(`America/New_York`). Loads in any time zone are converted first, so a load
indexed in UTC, New York or Tokyo bills identically. `TimeWindow.mask`
rejects timezone-naive input. A window's `start` and `end` are local clock
times: on DST change days an 08:00–22:00 window still covers 14 wall-clock
hours, which is 14 elapsed hours on both the 23-hour and the 25-hour day.

## Holidays

Holidays are generated by rule for any year from 1900 to 2200. Nothing is
cached for a fixed range.

| Holiday | Rule |
|---|---|
| New Year's Day | January 1 |
| Memorial Day | last Monday in May |
| Independence Day | July 4 |
| Labor Day | first Monday in September |
| Thanksgiving Day | fourth Thursday in November |
| Christmas Day | December 25 |

**No observed-day shift.** When July 4 falls on a Saturday, the Friday
before is an ordinary weekday; when it falls on a Sunday, the Monday after
is an ordinary weekday. None of the cited leaves provides an observed day.

### Holiday sets

Con Edison's holiday lists differ by rate and by season, so each window
names its own set. Every bundled set cites the tariff leaf that defines it.
Source document: PSC No. 10 – Electricity, full tariff PDF
(`electric-tariff.pdf`, 760 pp., sha256 `4141be1f…cb851f`, retrieved
2026-10-23 from coned.com).

| Set | Holidays | Source |
|---|---|---|
| `none` | none | Used where the tariff text names no holiday exclusion |
| `coned_six` (default) | all six above | SC 1 Rate IV Common Provisions, leaf 389.3 rev 1 (eff. 04/06/2020), PDF p. 622; same list in Rider leaf 327.2 rev 2 (eff. 11/03/2022), PDF p. 486 |
| `sc1_rate2_summer` | Independence Day, Labor Day | SC 1 Rate II summer on-peak, leaf 389 rev 23 (eff. 02/01/2026), PDF p. 618 |
| `sc1_rate2_nonsummer` | New Year's, Memorial Day, Thanksgiving, Christmas | SC 1 Rate II non-summer on-peak, same leaf |

A custom set can be given as a list of holiday names
(`["independence_day", "labor_day"]`). Unknown or duplicated names raise
`ConEdBillingError`.

### Lookups

- `holiday_date(holiday, year)` returns the civil date.
- `HolidaySet.dates(start_year, end_year)` returns all dates in a range.
- `is_coned_holiday(when, holiday_set="coned_six")` and
  `HolidaySet.contains(when)` return a plain `bool` for a scalar (`date`,
  `datetime`, `Timestamp`) and a boolean NumPy array for a `DatetimeIndex`
  or array-like. Timezone-aware times are converted to New York first;
  naive times are taken as New York wall-clock times.

## Windows

A `TimeWindow` selects intervals by month, day type, holiday and time of
day:

| Field | Meaning |
|---|---|
| `months` | 1–12, non-empty, no duplicates; `None` = every month |
| `weekdays_only` | `True` = Mon–Fri, `False` = Sat–Sun, `None` = every day |
| `start` | inclusive local start (`None` = 00:00) |
| `end` | exclusive local end (`None` = end of day) |
| `include_holidays` | `True` = holidays are not excluded (set `none`) |
| `excluded_holidays` | holiday set name, list or `HolidaySet` to exclude |

The holiday set used is `excluded_holidays` when given, `none` when
`include_holidays` is true, and `coned_six` otherwise. Giving both fields
is an error.

**Half-open.** A window covers `start <= t < end`, matched on the
interval's start time. 08:00–22:00 includes the 08:00 interval and excludes
the 22:00 one. Intervals are aligned to the clock grid (see
`load_data.md`), and every bundled boundary is a whole hour, so no aligned
5/15/30/60-minute interval straddles a boundary.

**End of day.** In YAML, write `end: end_of_day` (or omit `end`).
`"24:00"` is rejected with an error that points to `end_of_day`. Times must
be `HH:MM`, whole minutes.

**Overnight windows** (`end <= start`, e.g. 22:00–08:00) are rejected.
Write them as two windows. Con Edison off-peak periods are complements of
on-peak windows and are billed that way.

**Day type and holidays combine with AND.** A weekday window with holidays
excluded matches Monday–Friday non-holidays. A weekend window
(`weekdays_only: false`) still drops a holiday that falls on a weekend
unless holidays are included.

## SC-9 Rate II (finding N1)

Leaf 449 rev 20 (eff. 02/01/2026, PDF p. 688) defines the SC-9 Rate II
demand windows as "Monday through Friday" with no holiday wording, and
General Rule 10.10 (leaf 90 rev 4, PDF p. 104) defines off-peak as the
48 hours of Saturday and Sunday plus 10 PM–8 AM Monday–Friday. The text
therefore gives SC-9 Rate II no holiday exclusion. The bundled legacy YAML
still excludes holidays from both windows; it is kept unchanged as an
unverified legacy value, and the WP3 transcription uses set `none`.
