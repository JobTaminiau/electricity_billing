code                str            required  # name of rate
customer_charge     float          required  # fixed monthly price per customer
supply_charge       float          required  # market supply charge
merchant_charge     float          required  # merchant function charge
demand_delivery     list[Demand]   optional  # demand delivery charges
demand_supply       list[Demand]   optional  # demand supply charges
energy              list[Energy]   optional  # energy rates

Demand / Energy
└─ rate             float          required
└─ window           dict           required (may be empty)

Window fields (all optional)
    months          list[int]      1–12
    weekdays_only   true/false/null
    start           "HH:MM"
    end             "HH:MM"
    include_holidays true/false

Note (WP3): this is the legacy format read by load_rate. The validated, dated
schema is v1, documented in docs/tariff_schema.md (files under tariffs/v1/).
Unknown keys are rejected; the only optional free-text key is `notes`.
